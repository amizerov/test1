# DevTools redirect demo

Тестовый проект из двух HTML-страниц. При открытых инструментах разработчика
страница `2.html` перенаправляет пользователя обратно на `main.html`.

## Файлы

- `main.html` — главная страница со ссылкой на вторую страницу.
- `2.html` — защищаемая страница, подключающая проверку в `<head>`.
- `security.js` — обнаружение DevTools и перенаправление на главную страницу.

## Как проверить

1. Откройте `main.html` в браузере.
2. Откройте DevTools.
3. Перейдите по ссылке «Перейти на страницу 2».
4. После обнаружения DevTools браузер вернётся на `main.html`.

Для docked DevTools используется сравнение внешнего размера окна с размером
viewport. Для undocked DevTools используется замер паузы на инструкции
`debugger`. Проверка также повторяется после загрузки страницы.

> Клиентский JavaScript не обеспечивает настоящую защиту исходного кода:
> проверку можно отключить или обойти. Для защиты данных и контроля доступа
> необходима серверная проверка.
