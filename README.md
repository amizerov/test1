# DevTools redirect demo

Тестовый проект из двух HTML-страниц. При открытых инструментах разработчика
страница `2.html` перенаправляет пользователя обратно на `main.html`.

## Файлы

- `main.html` — главная страница со ссылкой на вторую страницу.
- `2.html` — защищаемая страница, подключающая проверку в `<head>`.
- `security.js` — обнаружение DevTools и перенаправление на главную страницу.

## Как проверить

1. Откройте `main.html` в браузере.
2. Откройте DevTools.
3. Перейдите по ссылке «Перейти на страницу 2».
4. После обнаружения DevTools браузер вернётся на `main.html`.

Для пристыкованной DevTools используется сравнение внешнего размера окна с
размером viewport. Проверка выполняется сразу при открытии `2.html`, а затем
повторяется при изменении размера окна, возврате фокуса и по таймеру.

Для режима мобильного устройства инструкция `debugger` выполняется в отдельном
Web Worker. Если DevTools приостанавливает worker, основной поток страницы
продолжает работать и выполняет редирект, не ожидая ручного продолжения отладки.
Перед проверкой worker коротко ожидает подключения отладчика, поэтому механизм
не зависит от выбранного профиля ограничения скорости сети.

Проверка рассчитана на пристыкованную DevTools. Надёжного браузерного API для
обнаружения DevTools, открытой в отдельном окне, не существует.

> Клиентский JavaScript не обеспечивает настоящую защиту исходного кода:
> проверку можно отключить или обойти. Для защиты данных и контроля доступа
> необходима серверная проверка.
